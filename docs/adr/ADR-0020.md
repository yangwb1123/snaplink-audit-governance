# ADR-0020: 导出所有者取消、关联重试与安全失败分类

状态：Accepted  
日期：2026-10-15  
关联：ADR-0013、ADR-0014、ADR-0016、ADR-0019；本批次不交付检查点续跑

后续：ADR-0021 仅增加 Put 后密封对象检查点/终态提交续跑；本 ADR 的 retry 仍是
新任务、新选择，不继承检查点。ADR-0023 后续增加生成前固定成员计划，retry 同样
不继承该计划；逐页/逐块生成续跑及业务执行仍不在已交付范围。

## 背景

租约和终态 fencing 不提供用户控制命令。不能把重试实现为原终态退回 pending，
也不能通过取消推断外部 Put 已停止。被 Hold 阻断的证据详情不能作为控制命令的
返回值；未知提交结果须可查询、幂等收敛，而不是盲目创建多份任务。

## 决策

1. 增加 `POST /api/v1/exports/{jobId}/cancel`（200）和 `/retry`（202）。沿用
   `audit:export:create`，服务端另要求同租户、已知 requested_by 精确匹配可信
   subject；平台凭证须显式选择单租户，不能绕过所有者校验。仅接受无 body、null
   或空 JSON 对象，不接受主体、筛选、状态、owner 或租约输入。成功和错误均
   `Cache-Control: no-store`，仅返回 ExportSummary，不返回证据/筛选/对象路径/
   摘要/事件数/原诊断。详情和下载仍重新检查授权、Hold 和认证、自审计。
2. pending 或元数据合法的 leased running 可原子转 cancelled、写 finished_at 与
   `export.cancelled`、撤销 lease、清空输出引用/摘要/计数；原 query 保留以便核对
   和关联重试。合法的 same-owner 重复取消零保存、不重复事实。其他终态、未知
   状态、无 fencing 的旧 running、错绑/畸形元数据失败关闭。已到期但尚未恢复的
   合法 lease 也可被所有者撤销，不能因此复活或重新领取原任务。
3. 取消撤销的是共享 control 中的运行权。远端/其他副本最多在后续 heartbeat
   观察撤销，既有 owner/终态 fence 拒绝迟到结果；不能承诺立即停进程、强杀 I/O
   或回滚。迟到 Put 可留下无引用 sealed WORM 对象，不发布路径、不删除对象。
   durable running/队列预算可释放，但这不是实际物理执行上限或完成回执。
4. finished 的 failed/cancelled 所有者任务可重试；带遗留 lease 的终态不推断可用。
   原任务保持不变，新任务保存 `retry_of`。继承原筛选但清除 cursor，重新选择当前
   证据、失败关闭读取自审计和 Hold 预检，并重新经过共享 pending/running 准入。
   新任务不继承原 started/finished、输出、错误或失败类别；领取仍走私有 lease。
   创建与重试各共享一次 Store operation deadline；预检用独立深快照捕获当前 Hold/
   证据目录，远端读取在 Store 锁外，不阻塞续期/所有者取消；没有消除历史物化成本。
   `export.created`、`export.retried` 与新任务在同一 control CAS 提交。
5. 同一共享 control CAS 内，每个原任务最多一个直接后继；重复请求返回该后继
   摘要，包括后继已经结束时。需要再试时显式指定失败/取消的后继，形成链，不
   自动复用原终态。CAS 重新核对原任务、所有者、完整筛选和唯一后继绑定；错绑、
   多后继、共同污染的 map/body identity 失败关闭。已存在后继的重复调用仅读
   control，不新建任务/成功事实或读取证据，因此不绕过当前 Hold。
6. 新增可选 `failure_code` 闭集：execution_failed、legal_hold、lease_expired、
   legacy_stuck、cancelled、unknown。新执行/恢复/取消保存固定类别，读端把任意
   非闭集持久值转 unknown，不能透传诊断；旧任务可以缺失，不从错误文本猜测。
   ExportJob/ExportSummary 增加可选 retry_of；治理导出计数新增 cancelled，不计入
   unknown。现有 Error/forbidden/reason=legal_hold 契约保持，类别不是物理停止、
   完整性、业务执行或重试成功的证明。
7. Web 在列表摘要和详情展示本人可用操作，确认后才写入；身份含 token/权限/
   tenant/subject，任务及身份变化撤销请求代次、确认和晚响应。成功导航/刷新后继，
   不凭摘要开放证据下载。错误/超时可能已提交，先只读刷新核对，不自动重发写入。
   Token、筛选和诊断不进入持久存储或查询 URL；新 URL 仅使用作业 ID 与租户选择。

## 成本、验收与不支持项

- 唯一后继检查扫描 retained control 导出历史，未解决历史物化、共享 control CAS
  成本、整块 JSONL/AEAD 内存、实际外部 I/O 或跨副本严格公平；旧 PG v1 仍可能
  物化旧快照。只能在同一共享 control CAS 内保证准入和关联幂等，不跨数据库。
- 新重试不是旧固定成员快照的续跑：迟到事件/当前证据变化可影响新任务。不交付
  检查点、分块密封/认证下载、自动恢复执行或业务补偿；批准仍不等于业务执行。
- 代码/契约、完整 quality、Web 类型/lint/build/单测分别验收；专项回归在真实
  Save/Put、文件重启和 PostgreSQL 17 独立连接池 CAS 边界覆盖取消、晚提交、未知
  保存、职责/租户隔离、单后继与共享预算。组件 race 不等于整栈/容量/容灾/正式
  WORM 或业务协议验收，安全扫描仍须独立运行并保留失败。
- 本机最终完整 quality 退出 0（普通 Go 含缓存 239.2s、全量 uncached race 364.4s、
  vet/build、Python 156/1 可选跳过及全部门禁），Web 24 文件/97 测试与类型/lint/build
  通过，真实 PG 独立连接池专项三轮 race 通过。安全扫描退出 1，同一 gosec 7 项及
  未调用模块警告保留；不以此 ADR 的实施接受代替安全发布批准。详见安全扫描记录。

## 升级、备份与回滚

- 无新增 SQL 表/迁移、scope 或证据格式变更；REST 增为 33 路径/41 操作。
  control 增加作业状态/可选元数据，保留私有 export_leases。API/worker/Web 应
  配套升级；不能混跑旧执行器或会丢弃新字段的旧控制面 writer，即使旧版本已经
  支持 lease。旧二进制忽略 retry_of 会破坏幂等关联，不能让它重写共享 control。
- 先停止新领取/写入，核对活跃执行与未知 Put。备份整个 control（包括原任务、
  后继关系、失败类别、leases）及既有 ledger/hot/journal/发布确认/密钥，不手改
  requester、重置终态、删除后继元数据或 WORM 对象来重试。终态/关联历史尚未 GC；
  未来 GC 必须另行设计，不能删后继后继续声称原幂等保证。
- 回滚前停止新版本领取和控制写入、核对远端未知结果，保留新版本可读备份并评审
  目标版本的字段保存能力；不能将旧版本成功启动、running=0 或配置一致性键当作
  状态/证据已安全回滚的证明。文件账本仍单写者，数据和时钟要求遵守 ADR-0017/0019。
