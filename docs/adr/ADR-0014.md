# ADR-0014: 导出队列预算、有界公平调度与锁外下载读取

状态：Accepted  
日期：2026-10-08  
关联：ADR-0013；本决策不交付租约、检查点或分块导出

后续：ADR-0019（2026-10-14）补充私有租约/心跳、过期 fencing 与部署边界；
下述第 5 项是本决策当时的限制。ADR-0021 后续仅增加 Put 后密封对象检查点与
终态提交续跑；ADR-0023 后续在生成前增加 selected 固定成员计划，接管仍占同一
running 槽，不扩大预算。逐页/逐块生成续跑和分块导出仍未交付。
ADR-0037 后续只修本地 reservation：保留至原最后一次有界 control 尾读结束，再原子
释放并登记有限后继 wake；终态可见不当作执行器退出，不新增shutdown协议或改共享预算。

## 背景

CreateExport/ResumePendingExports 原来为每个 pending 任务启动 goroutine，队列和并发
没有统一预算。CAS 领取只防止同一任务双跑，不能阻止不同任务跨副本放大资源占用。
整块封装下载已有认证及超时边界，但远端 Get 在 Store.mu 内执行。

## 决策

1. 每个共享控制文档最多 128 个 pending/running 导出，单租户最多 32 个。
   创建时在同一次 CAS 保存内重新检查，耗尽返回 quota_exceeded/429，不创建 job 或
   export.created；原有授权、查询读自审计和 Legal Hold 前置拒绝仍不绕过。
   终态不占队列配额，也不被调度器删除；此预算不声称控制文档所有历史成本有界。
2. 每个进程只有一个有限 dispatcher，至多两个导出执行 goroutine，不为全部 pending
   记录分配 goroutine。租户按身份轮转，租户内按 CreatedAt/ID oldest-first。
   本地保留项和 durable running 不重复计数；dispatcher mutex 不跨 Store/归档调用。
3. 领取 CAS 同时检查共享控制文档 running 数：全局最多 2 个、单租户最多 1 个。
   API/worker 共用预算，不以进程 semaphore 冒充跨副本准入。失败关闭、不临时提高
   配额；已有超预算 running 不回退终态或强行删除，而是停止新领取。
   轮转位置是进程内公平提示，不是跨副本严格全局排程或 SLA 承诺。
4. 创建和恢复只唤醒 dispatcher；ResumePendingExports 返回观察到的 tenant backlog，
   不是已领取或完成数。后台调度可处理同一 Service 的已授权 durable 租户作业，
   不将前台调用的 subject 改作其他作业申请人。API 启动立即唤醒并每秒重查；
   完成继续唤醒，失败的 pending 不 hot-spin，留给周期或 worker 下一轮重试。
5. 不增加租约/心跳/检查点：running 崩溃残留会占并发，须依靠既有 governance worker
   RecoverStuckExports 收敛；started_at 优先、旧 CreatedAt 回退和严格边界不变。
   不重新将同一终态变 pending，不把排队年龄作为运行年龄。退出停止队列唤醒；
   已执行任务沿用既有 detached/有界 Store、归档 Put/终态保存和卡死恢复语义。
6. ReadExportObject 改为 WithOperation 共享一次 deadline，锁内只从 control 复制已完成
   job 的租户/对象路径，锁外 Get。503 store_timeout、取消 499、缺失 404 和无凭证
   错误消息保持；返回的是 sealed bytes，传输仍须 tenant/job AEAD、格式/摘要认证及
   Legal Hold/下载自审计通过后才输出明文。不是未经认证的分块流下载。

## 限制、验证与运维

- 文件后端仍单写者。共享预算以同一个 PostgreSQL control CAS 为边界；不同数据库
  或多份文件账本不共享配额。大历史物化/排序、整块 JSONL+AEAD 内存仍待改造。
- 恢复 worker 必须运行并与 API 使用相同签名/加密/归档配置；卡死运行占满预算时，
  先核对真实 worker/任务状态，不通过放宽配额或修改终态换取吞吐。
- 单元/race 覆盖租户轮转、租户内顺序、本地/持久计数去重、CAS 拒绝不修改 pending、
  多 Service 共享 Store 并发和队列创建预算；Get 边界阻塞时控制写可完成，验证锁外
  下载及原有 timeout/认证/Hold 路径。实际 PG 负载、公平性与容量验收独立记录。
- 本决策不涉及身份、业务恢复执行、WORM 删除/留存缩短、取消/关联重试协议、
  生命周期或历史密钥轮换。只能按实际交付分别勾选 M3 子项。
