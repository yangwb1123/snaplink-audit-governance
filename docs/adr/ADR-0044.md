# ADR-0044: 既有留存配置的控制面读取与单次预算

状态：Accepted  
日期：2026-10-18  
关联：ADR-0016、ADR-0017、ADR-0019、ADR-0033、ADR-0039、ADR-0043

## 背景与有限范围

GetRetentionPolicy 只观察 control 配置，却经通用 Store.Read 物化所有租户 hot/cold。
真实文件相同 control、1→32个无关 hot 事件使该读取分配509→4561；真实PG证据表锁
会耗尽其原caller预算，无关坏冷记录也会拒绝配置观察。Load返回有效快照但同时取消/
耗尽预算时，原实现仍可能输出配置。这些依赖不是留存评估或必要事件读自审计。

仅修既有配置读取，不扩产品能力。此局部物化/锁依赖与撤回输出的确定性复现，不证明
旧service累计10m或原导出running唯一根因；旧0014自验/独立失败与同源码收尾通过
均保留，不以最后一次绿、瞬时fsync栈或非受控wall差值推导死锁/宿主磁盘唯一归因。

## 决策

1. GetRetentionPolicy显式使用现有ReadControl，v2不物化hot/cold、不查询证据表或
   Get/Put WORM。每次调用观察当前control，不缓存或Save捕获值。原按可信tenant
   key读取、缺配置404与空scope拒绝保持，不新增当前tenant注册前置或默认配置。
   原字段/天数/类别原样返回、标量值独占，不把配置解释为可删除或合规完成。
2. 一次WithOperation覆盖读取及捕获后context检查；ReadControl/v1回退继承原
   deadline，不重启预算或重试Load。预取消不Load；底层错误、超时或迟取消零返回
   配置，保留原错误/一次deadline分类。不把未知写的元数据观察当自动重发授权。
3. 不Save、不追加事实，保留配置元数据原静默读策略，不削弱事件/回执等必要读事实。
   原HTTP权限、tenant选择、错误包和缓存行为不变；不宣称完成M1全部边界矩阵。
4. EvaluateRetention仍独立读取原证据/当前Hold、沿用其原分离操作预算与评估语义；
   其策略观察同样只看 control，但不加公开读取的预取消闸门：worker 的跨租户中止契约
   要求在途租户仍走完 recovery→seal→aggregate→archive→retention 整步（原
   `pass_aborted` 固定回归），评估本身只读且仍受该次 store 操作预算约束；
   此处不将其改成控制面统计、不隐藏坏证据、不删除事实、释放Hold或缩短COMPLIANCE。
   当前Hold、必要读自审计、lease/阶段fencing、终态不回退和共享128/32、running2/1
   继续独立权威。配置读取不是证据认证、完整性或生命周期/业务执行回执。

## 验证、兼容与限制

- 实际Load边界覆盖成功/原错误、预取消、带有效快照的迟取消/实际deadline及更早
  caller预算；零Save/append/WORM，原租户/404、历史配置与返回独占分别回归。
- 真实两租户文件/归档、认证selected计划与当前Hold、未知control temp、control及
  四份hot/cold字节/inode/版本、完整事实与重启保持。分配对照仍用默认文件系统、
  原归档源/Put/fsync及额外32个逐次真实Ingest/Save/append/fsync的hot事件；只测
  同一配置读取的分配，不测准备或吞吐，不批量内存化文件测试/迁移测量对象。
- PG17独立pools实际锁住两张证据表，先证明全局物化耗尽原短caller预算，配置观察
  则可读并看到另一pool新配置；健康续期使用推进后的共享时钟，原所有者取消/晚写
  fencing和完整证据/control/精确版本增量保持。持久坏冷记录不拒绝纯配置观察，
  但坏目标回执与实际control Load故障仍失败，不缓存/猜修复，原读事实不增不减。
- 无新字段/路径/scope、SQL/迁移、topic/Proto或持久/密封格式；文件单写者、共享PG、
  完整备份/停写升级回滚保持，不动历史/WORM/未知temp/旧卷。v1、共享control历史、
  EvaluateRetention/通用Update及其余全历史/锁内成本未整体改造，不作容量或长期
  稳定性保证。M1/M2/M3整体仍Partial，M4/M5协议与正式合规等继续独立待办。
- 专项/真实PG、全service逐测试/原导出阶段、完整quality/Web/security及随后独立
  验收分别绑定源码留证；不以专项代替全量或本ADR预授独立passed。安全扫描非零
  仍阻塞发布，不改规则/阈值、生产deadline、原5秒等待/10m包上限或自授豁免。
