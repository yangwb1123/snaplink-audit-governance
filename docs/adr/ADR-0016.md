# ADR-0016: 权限过滤的租户治理控制面摘要

状态：Accepted  
日期：2026-10-12  
关联：ADR-0013、ADR-0014；不扩展身份授权或业务执行协议

## 背景

导出/恢复已有分页工作台，但概览只依赖事件读取，不能为单功能权限提供治理负载视图。
将任务状态、Hold 数量、配置、发布或投影水位混作一个健康分数会误导运营，并可能泄露
没有读取权限的治理数据。逐个列表取全量详情还会复制敏感筛选、原因和证据元数据。

## 决策

1. 增加 `GET /api/v1/governance/status`，只读取一个明确租户的 control 元数据。
   JWT 租户 claim 为权威，query 不能覆盖；平台必须提供非空唯一 tenant_id。
   tenantless Console 的跨租户读取能力不授权本接口。至少需要以下现有权限之一，
   不临时发明新的 Snaplink 正式 scope：

   | 分区 | 所需权限 |
   |---|---|
   | exports | audit:export:create |
   | restores | audit:operation:read |
   | restores.actionable | audit:operation:read **及** audit:legal_hold:manage |
   | legal_holds | audit:legal_hold:manage |
   | retention | audit:policy:read |

   鉴权一次，返回分区逐项过滤。无权限的分区省略，不是零计数，也不以聚合权限赋予
   详情、下载、申请或决策能力。actionable 只数 pending_approval、非本人且申请人已知的
   任务；只是提示，决策仍执行既有原子职责分离检查。
2. 只提供当前保留的作业状态计数、本人待审批数、Hold 有效/释放数和策略配置；
   不限最近 24 小时，不读取/推断事件量或阻断导出的 Hold 覆盖范围。不输出载荷、
   筛选、对象路径、密文/摘要、申请人身份、原因、任务 ID 或诊断。未知作业/决策状态
   单独计数，不映射为成功。租户固定队列/运行上限复用实际准入常量，不暴露全局用量，
   不是可用配额；最早排队时间来自非零 CreatedAt，不冒充进度、运行年龄或心跳。
3. 整次 ReadControl 与自审计使用一个 Store.WithOperation deadline。闭包内不调用
   其他导出 Store 方法；摘要拥有自己的元数据副本。成功之前追加一个独立的
   `governance.status.read` 读事实（可信 actor、固定分区名，无计数/筛选/证据）。
   保存失败、冲突、取消、超时不返回任何部分结果；无效/未授权 scope 不先做数据读取。
   返回头（包括错误）为 Cache-Control: no-store。
4. 明确 `source=control`、`completeness=not_asserted`，observed_at 是控制面捕获时刻，
   自审计追加是另一耐久边界，非跨后端事务快照。不扫描 Ledger、不读取 WORM、不检查
   broker/ClickHouse/发布确认，不把 control 当作证据事实源或完整性证明。
5. 恢复只表示 pending_approval/approved/rejected；`execution=not_tracked`，不调用
   业务 API，批准不等于执行成功。导出 completed 不保证当前可下载；详情/下载的 Hold、
   AEAD/摘要认证和自审计仍权威。Hold active 仅表示无 ReleasedAt，不证明对象版本
   保全。策略 configured 仅表示存储配置，既不是生命周期执行，也不是 COMPLIANCE
   到期、可删除或全历史留存校验，不改变事实/TTL/Hold/COMPLIANCE。
6. Web 在概览独立加载此摘要，即使没有事件读取权限仍可展示授权治理分区。只在内存
   保存结果/身份绑定，URL 只有 tenant selector，不持久化 Token、筛选或摘要。
   租户、主体、Token 或权限变化时清结果/错误、取消请求并推进代次；拒绝忽略取消的
   A→B→A/旧身份晚到响应。服务失败不冒充零计数，刷新/重试仅对这个只读操作执行。

## 限制与验证

- 仅用 ReadControl 并不意味着历史扫描成本已解决：v1 PostgreSQL 仍可能加载旧快照，
  v2 的共享 control 也保留全部终态作业和 Hold。循环继承取消，但生产容量另行验收。
- 不新增迁移、租约、检查点、重试/取消、版本级 Hold、生命周期、密钥轮换、业务回执、
  发布/投影完整性或跨副本配额。这些仍为独立规划和验收条件。
- 回归覆盖租户/平台选择、每个最小权限及组合、tenantless Console 拒绝、零/未知状态、
  本人/旧申请人排除、配置副本、无归档 I/O、读自审计失败/冲突、共享 deadline 和真实
  追加边界取消；Web 覆盖概览接线、权限过滤、Token/权限改变、A→B→A、取消被忽略、
  卸载、失败非零状态和租户不匹配。完整工程/Web 门禁与发布扫描独立记录。
