# ADR-0030: 普通事件查询参考初页的认证前置与可信敏感条件

状态：Accepted  
日期：2026-10-17  
关联：ADR-0002、ADR-0013、ADR-0019、ADR-0026、ADR-0029

## 范围与背景

普通固定成员查询的 referenceQueryEvents 已经锁外 Get，但热正文仍在 Store.Read 闭包内
未经内容认证即参与所有筛选；被改坏的 actor/time/tenant 等字段可以隐藏 committed
证据。归档候选也未核对 receipt map/body 与精确 Schema 正文身份；缺失的 indexed
正文可能被跳过。保存的搜索 sidecar 不受 SourceDigest 认证，不能决定固定成员集。

本切片只改普通事件查询的 **ledger-reference 首次成员选择**，复用已有 Console 的
认证扫描，不重复计功锁外 Get、固定成员游标或 Console。ClickHouse 候选/失败不降级、
续页按原坐标取证、原导出阶段/当前 Hold/lease fencing/预算与终态不回退均不改变。
无需新的外部业务授权，不涉及恢复执行、对象删除或保留期调整。

## 决策

1. reference 初次选择与 Console 共用 authenticatedQueryEvents。Store.Snapshot 捕获
   独立深副本；只有捕获/物化持 Store.mu，源 Get、精确认证、敏感原值重建与谓词锁外。
   不保存捕获快照覆盖并发目录、终态、lease、Hold、策略、计划/页/检查点。捕获目录是
   本次观察点，不是跨后端原子快照；新调用重新捕获，不能混用随后目录换成功。
2. 从目标租户 committed receipts 锚定，map key 或 receipt 正文属于该租户时均核对
   tenant/event 绑定，再验证热/WORM 正文身份、精确 Schema tenant/id/version、重建
   内容和链 hash，最后才评估任何查询条件。本租户坏/缺 committed 证据失败关闭，
   不能藏为空匹配、跳过或输出部分 items/count/cursor；缺失 indexed 正文不是空事实。
   hot-only/journal 不是成员；其他租户完整证据不 Get/认证。缺失精确版本不取最新版本
   替代；停用历史 Schema 不影响按其精确定义读取。
3. payload_field 仅在精确 Schema 声明 searchable 且存在时匹配；从认证原值按**条件
   自身**的 bound/legacy 格式重算，不信任保存 sidecar 的存在、值或格式，保持大整数
   精度及 bound tenant/field 隔离。内部解密只用于认证/匹配，不能用明文替换响应中的
   保护字段；HTTP 仍递归剥离 sidecar。敏感条件仍强制 ledger adapter，不发给投影。
4. 这是普通新查询的明确兼容演进：原加密 searchable 字段只支持同格式 sidecar 匹配
   的限制不再适用于本 reference 初次选择；认证重建后 bound/legacy 均能匹配同一原值。
   旧 digestMatches helper 及其他尚未改造的兼容调用保持原行为，原限制仍有直接回归；
   新服务级回归同时要求跨格式正确匹配且响应保持原密文。不是降低加密或新增权限。
5. 沿用最多 10000 个**匹配身份**，超限返回原 429/quota_exceeded，不截断成功；共用
   helper 不给 Console 事件页/facets 新增此上限或改变它们的 live/count 口径。普通查询
   仍按 occurred_at/sequence/event_id 排序形成 15 分钟固定成员集，4 MiB/tenant16、
   HMAC scope/source/subject/filter/page-size 绑定不变。新提交/迟到成员只在新查询出现；
   保存过的旧成员集不因本次算法变化重选，续页不重扫已服务前缀或评估当前 sidecar。
6. 原 queryEventsSnapshot 的一次 deadline 继续覆盖捕获、Get/认证/选择、成员元数据
   Save 与恰好一次失败关闭读自审计；原超时/取消分类及计数不变。最后还检查 ctx.Err，
   追加后取消也不服务结果。内部空 actor 仍零读事实。未知追加/Save 不等于回滚；已
   耐久的尝试事实或未返回 cursor 的运行成员元数据可保留至原回收边界，不能宣称读取
   与元数据/事实是跨后端原子提交，或用追加事实证明字节已交付。
7. GET events 与 POST events:query 保留原租户/权限/错误/no-store/DTO；敏感条件仅走
   已有 POST body，不新增 URL、日志或浏览器持久化。平台仍须显式单租户选择，签名
   tenant claim 权威，不获得 Console 的 all-tenant 例外。导出创建/新后继原委托查询
   自然继承认证，但随后 ADR-0029 当前 Hold CAS 预检保持独立权威，不因查询通过放行。

## 成本、兼容与未交付项

无新字段、路径/scope、topic、Proto 方法、SQL/密封格式或持久模型，无需迁移。以前被
条件隐藏的损坏或错绑证据现在会拒绝整个初页；须修复原证据/目录，不能删历史、改身份/
版本、伪造 receipt 或降低认证换成功。旧 writer 的字段保存/停写升级要求仍适用。

仍深物化历史、排序 receipt keys 并认证扫描本租户 committed 证据；匹配上限、page_size
和 deadline 不是源扫描/字节/恒定内存/容量 SLA。旧全量 timeline/aggregate replay、其余
兼容 helper/历史成本、ClickHouse facets/完整性、导出最终整块合并/密封及流式认证下载、
其余跨副本准入、M4/M5/整栈/容量/正式合规仍未完成，M3 整体仍 Partial。

后续 ADR-0031 单独加固当时未改的旧全量时间线/服务层聚合回放：复用认证源、锁外
取证与各自共享预算，原上限/排序/读事实和零业务副作用不变，无新 HTTP 路由。它不
重复交付本 ADR 的 reference 初页，也不消除上述历史物化/认证扫描成本。

## 验证与部署边界

先新增回归确定性复现热谓词隐藏、receipt/Schema 错绑、missing indexed body 和 sidecar
误选，再验证热/冷/加密/明文/精确数字与双格式、字段/租户/searchable 绑定、原 10000
边界/Console 不限、owned 目录/输出、一次 Load/Get/append deadline、取消/未知追加与
零结果。真实 FileStore Get 暂停时同 Store 续期/取消和 control 可提交；真实文件重启
保留故障/原 receipt/Schema、固定成员续页只读本页。独立 PG pools 覆盖耐久成员共享、
真实持久谓词/sidecar 故障与并发终态/Hold/策略不被覆盖；HTTP 覆盖授权先于 Get、
body-only 敏感筛选、no-store/摘要剥离/固定脱敏错误。内存矩阵不当作文件耐久性证明。

完整 quality/Web/security-scan 与组件命令分别记录真实退出码和源码绑定，不能以专项/
模型报告代替随后独立工程验收或安全发布批准；安全扫描非零继续阻塞发布。不清理未知
对象、原 ledger/journal/WORM/历史或旧卷，不缩短 COMPLIANCE，不产生业务执行副作用。
