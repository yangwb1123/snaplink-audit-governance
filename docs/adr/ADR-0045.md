# ADR-0045: 跨租户单事件读取的锁外归档认证与单次预算

状态：Accepted  
日期：2026-10-20  
关联：ADR-0017、ADR-0025、ADR-0031、ADR-0032

## 背景与有限范围

`GetEventAcrossTenants` 是平台读使用的旧跨租户单事件兼容 helper：它按全局唯一的
event_id 解析，跨租户重复 id 必须歧义失败关闭。原实现在 `Store.Read` 闭包内对
已归档 receipt 逐个执行 `Archive.Get` 并重建认证，即持有 `Store.mu` 做远端 WORM I/O；
慢对象存储会阻塞所有租户的无关控制写。读取与随后的读自审计也各自计预算。

本切片只修该既有 helper，不新增路由/字段/scope，不改变 Console all-tenant 授权、
普通事件查询/单事件/时间线/回放/导出/恢复的既有语义，也不把兼容 helper 提升为
新的生产入口。

## 决策

1. 一次 `Store.WithOperation` 覆盖捕获、归档认证与一次读自审计。捕获仅在
   `Store.Read` 内克隆命中热事件并记录已归档 receipt 身份；不 Get WORM、不重建
   正文、不 Save 旧快照。
2. `Store.mu` 释放后才对本次捕获的 archived receipt 做一次 `archiveFallbackContext`
   派生预算内的 `Archive.Get`，沿用现有身份/内容/链哈希认证；多 receipt 仍共用
   一次 archive 上限，不按 receipt 逐个重新计时，也不重启服务操作 deadline。
3. 歧义与缺失语义不变：零匹配 `ErrNotFound`，跨租户多匹配固定 conflict，不按
   map 顺序选租户；任何归档/认证失败零事件输出，不追加成功读事实。
4. 唯一匹配后以事件自身 tenant 追加一次 `audit.event.read`，与捕获/认证共享同一
   operation 上下文；追加失败或调用方撤回时不输出事件，已耐久尝试事实不撤销。
   不扩大平台读取授权，不把该 helper 当完整性或下载授权。

## 兼容、成本与验证

无新路径/scope/公开字段、SQL/迁移、topic/Proto 或持久格式。热事件与归档事件仍返回
独立副本；归档对象淘汰前后结果一致。收益是慢 WORM 读不再持有 `Store.mu`，并让
捕获/认证/自审计共享一次 deadline；不改变全历史扫描成本，也不证明生产容量。

回归用真实文件归档与暂停 `Archive.Get` 的确定边界：阻塞期间并发 `UpdateControl`
必须完成；归档失败零事件/零读事实；调用方 deadline 撤回零事件/零读事实；既有
hot/archived 独占副本与热归档混淆用例保持。完整 quality/Web/security/diff 及随后
独立工程验收绑定同一稳定源码；安全扫描非零继续阻塞发布，未改规则/阈值/豁免。
