# ADR-0041: 既有来源更新的控制 CAS 与当前记录重判

状态：Accepted  
日期：2026-10-18  
关联：ADR-0001、ADR-0006、ADR-0014、ADR-0017、ADR-0019、ADR-0020、ADR-0023、ADR-0024、ADR-0033、ADR-0040

## 背景与有限范围

UpdateSource 只替换 control 中的既有来源配置并追加一次 source.updated，却走通用
Store.Update。真实文件 v2 因而重写未变 hot/cold 并推进 hot 版本；真实 PG Save
冲突后，兼容路径可能再次保存旧整份 control，覆盖并发导出取消/续期/阶段、恢复
决定、Hold、策略与其他来源，甚至恢复已不存在的 tenant/source。原返回值在 Save
失败或结果未知时仍带请求来源，不应被嵌入调用方当成已确认的更新结果。

本决策只修上述既有更新，不改 AddSource、通用 Store.Update、身份发行/授权协议或
新增产品能力。确定性文件/PG复现是局部写放大与控制覆盖依据，不是旧 service 累计
10m 超时/原导出 running 的唯一根因证明。旧0014自验/独立失败与同源码收尾完整
通过都保留，不能以局部修复或最后一次绿抹消。

## 决策

1. UpdateSource 显式使用现有 UpdateControl。每次真实 Save 冲突后，在新鲜 control
   上重新检查当前租户和来源；缺失仍404、零成功保存。原请求替换自身来源字段，
   CreatedAt 仍取当前存量记录，不沿用冲突前的创建时间，也不新增条件更新协议。
2. 原 normalizeSource、key framing/归档组件长度/资源上限、精确 allow-list 的去重/
   trim 拒绝与排序保持。原空列表只允许 client_id=source.id，Active=false 仍可禁用，
   signed client/tenant 的解析与零命中/歧义失败关闭不变；不扩展用户/身份领域状态。
3. 仅原来源替换与一次原 source.updated 同 CAS；相同值的再次更新仍各一次事实，
   不新增 no-op 或请求幂等。不写旧物化快照覆盖当前导出终态、lease、selected/页/
   sealed、恢复决定、Hold、策略或邻居来源，v2 不替换 hot/cold，不 Get/Put WORM
   或增加独立读事实。当前 Hold/必要读自审计、共享预算及 owner/阶段 fencing 权威。
4. 一次原 operation deadline、有限冲突重试/退避与取消/超时分类保持。任何失败/
   未知 Save 返回错误与零 SourceSystem，不把未确认请求当成功；已耐久配置/事实
   不撤销，先只读核对，不把 fsync/rename/close/取消错误当回滚或盲重发授权。HTTP
   原本即在错误时只返回错误包，无新增线面字段、错误码、权限或成功状态。

## 验证、兼容与限制

真实两租户文件、原 FileStore 归档/淘汰、认证 selected 计划和当前 Hold 回归：修前
启用/禁用与未知 control temp 阻断均替换四个 hot/cold inode，两个 hot 字节/版本
变化；修后核对原字节/版本/inode、完整逻辑证据/控制/事实和关闭重启。未知 temp
原字节保留，原精确冷回执仍可读，当前 Hold 仍拒绝导出。更新本身零源 I/O/读事实。

真实 PG17 独立 pools 用 control 行锁和 pg_blocking_pids 确认实际 Save 在途后，再
提交并发取消或健康续期、恢复决定、当前 Hold、策略和邻居来源。selected/真实页/
sealed 三阶段均检查完整证据、版本增量与晚 owner 零控制发布；续期推进共享观察
时钟并在竞争前后核对运行权。自有缺 tenant/source 及同 key 当前记录变更故障另验
重判404或保留当前 CreatedAt，不新增删除/重建 API。自有 goroutine 早退也取消/join。
Backend.Save 另覆盖有限冲突/耗尽、明确失败、真正提交后报错、实际 deadline、
取消及提交后取消，核对单次预算、原事实和零失败结果。原 allow-list/停用/默认绑定、
同值两次事实、调用方输入与返回切片独占另验；不以这类矩阵替代文件或 PG 持久验收。

无新字段/路径/scope、SQL、topic、Proto方法、持久/密封格式或迁移。既有备份须保留
完整 control（含来源配置、任务/关联/lease/阶段/决定）、ledger/hot/journal/确认与
原密钥，停写升级/核对回滚，不混跑会丢字段或覆盖控制的旧 writer。文件仍单写者，
共享 API/worker 使用 PG；不删历史/未知对象/temp/WORM/旧卷，不缩短 COMPLIANCE。

AddSource、通用 Update/v1、全历史/锁内物化和其他兼容成本仍在。全 service race/
JSON逐测试及原导出阶段、专项/真实PG、完整quality/Web/security和随后独立验收
分别绑定源码留证；少写四个文件不等于整包 wall 下降、容量SLO或全部累计耗时/
历史 running 根因闭环。M1/M2/M3总项仍Partial，M4/M5业务协议、整栈/Hosted Login、
容量/容灾/正式合规独立待办；安全扫描非零继续阻塞发布，本ADR不授予安全豁免。
