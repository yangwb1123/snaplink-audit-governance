# ADR-0042: 既有来源创建的控制 CAS 与当前唯一性重判

状态：Accepted  
日期：2026-10-18  
关联：ADR-0001、ADR-0006、ADR-0014、ADR-0017、ADR-0019、ADR-0020、ADR-0023、ADR-0024、ADR-0033、ADR-0041

## 背景与有限范围

AddSource 仅新增 control 中的来源配置与一次 source.created，却仍走通用 Store.Update。
文件 v2 因而替换未变 hot/cold 并推进 hot 版本；PG v2 兼容路径在真实 Save 冲突后会
重用旧整份 control，覆盖并发导出取消/健康续期/阶段、恢复决定、当前 Hold、策略或
邻居来源。同 key 的首个来源注册也可能被覆盖或重新启用；当前租户消失仍可能按旧
观察创建成功。这与 ADR-0041 已修的 UpdateSource 是不同的既有提交入口。

本决策只修来源创建，不扩产品能力或身份协议，不改通用 Store.Update/CreateTenant。
确定性文件/真实PG复现支持局部写放大与控制覆盖修复，不证明旧 service 累计10m
超时/原导出 running 的唯一根因。旧0014自验/独立失败与同源码收尾通过均保留。

## 决策

1. AddSource 显式使用现有 UpdateControl。每次实际 Save 冲突后，在新鲜 control 上
   重查当前 tenant 与同 tenant/source key 唯一性；缺租户仍404，重复仍409，保持
   404优先于409。首个同 key 来源及其原创建事实不能被覆盖或被败方重新启用。
2. 原 normalizeSource、key framing/归档组件长度/资源上限、allow-list精确值校验、
   去重/trim拒绝与排序保持。原 CreatedAt 缺省在进入提交前只生成一次，提供的时间
   保持；创建 Active=false 仍按原规则默认true，停用继续走既有 UpdateSource。
   调用方切片不被排序或别名写入，空列表仅同ID客户端；signed client/tenant解析、
   跨租户同 client/source 歧义失败关闭不变，不发明全局注册唯一性或身份发行能力。
3. 只有原新来源与一次原 source.created 同CAS提交，不重写v2 hot/cold，不将旧物化
   快照覆盖当前导出终态、lease、selected/生成页/sealed、恢复决定、Hold、策略或
   邻居来源。创建本身零WORM Get/Put、零独立读事实；当前Hold、必要读自审计、
   共享队列128/32、running2/tenant1与owner/阶段fencing继续各自权威。
4. 原一次operation deadline、有限冲突重试/退避及取消/超时分类不变。失败/未知Save
   返回错误，已经耐久的注册/事实不撤销；先只读核对未知结果，不把close/sync/
   rename/Save失败当作回滚或自动重发依据。重复创建仍409，不新增请求幂等。
   原HTTP成功/错误包、权限与tenant选择不变，没有新增线面字段或错误码。

## 验证、兼容与限制

真实两租户文件、FileStore归档/淘汰、认证selected计划和当前Hold：缺省/提供创建时间
分别覆盖成功/重启与未知control temp阻断，核对四个hot/cold的字节/版本/inode、完整
证据/control/事实不变；重复注册零control替换，原精确冷回执重启仍可读，当前Hold仍
阻断导出。未知temp原样保留，不猜成功、不删WORM，不改变原文件系统测量对象。

真实PG17独立pools通过control行锁与pg_blocking_pids同步实际Save，再提交并发取消/
健康续期、恢复决定、当前Hold、策略与邻居来源；selected/真实生成页/sealed均核对
完整证据/版本和晚owner零发布。续期实际推进共享观察时钟、验证当前运行权，同时
检查本次来源缺省时间未被CAS重试重新生成。同key首个注册、租户缺失及二者同时
发生另验当前唯一性/404优先级；败方不能覆盖或激活首个来源。自有goroutine早退也
取消/join，不用默认门禁跳过可选PG测试冒充实际执行。

Backend.Save覆盖明确失败、真正提交后报错、有限冲突/耗尽、实际deadline与取消，
保留单预算与一次事实。文件故障夹具仍用原三个管理API初始化；Source和Schema现在
各计一次真实control写，累计counter不清零，实际armed失败/disarmed成功序列及原
Ingest增量断言均保持。这不是将文件测试内存化、减少fsync或放宽任何等待/deadline。

无新字段/路径/scope、SQL、topic、Proto方法、持久/密封格式或迁移。完整control
（含来源、任务/关联/lease/阶段/决定）、ledger/hot/journal/确认与原密钥一起备份，
停写升级/核对回滚，不混跑会丢字段或覆盖当前控制的旧writer。文件仍单写者，共享
API/worker使用PG；不清历史/未知对象/temp/WORM/旧卷，不缩短COMPLIANCE。

CreateTenant/通用Update/v1、共享control历史与全历史/锁内物化成本仍在。全service
race/JSON逐测试与原导出阶段、专项/真实PG、完整quality/Web/security及随后独立
验收分别绑定源码留证；少写四个文件不是整包wall下降、容量SLO或长期稳定性闭环。
M1/M2/M3总项仍Partial，M4/M5业务协议、整栈/Hosted Login、容量/容灾/正式合规
独立待办；安全扫描非零仍阻塞发布，本ADR不授予安全豁免或发布批准。
