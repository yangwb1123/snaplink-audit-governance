# ADR-0039: 既有留存配置写的控制 CAS 重判

状态：Accepted  
日期：2026-10-18  
关联：ADR-0014、ADR-0017、ADR-0019、ADR-0020、ADR-0023、ADR-0024、ADR-0034、ADR-0038

## 背景与有限范围

SetRetentionPolicy 只改变 control 中的配置与一次原事实，却调用通用 Store.Update。
真实文件 v2 因而替换四个未变 hot/cold 文件并推进 hot 版本；实际 PG Save 冲突后，
兼容路径可能将旧整份 control 再次保存，覆盖并发取消、续期、计划/页/检查点、恢复
决定、当前 Hold 或另一租户策略，甚至恢复已撤销的运行权或已不存在的租户。

本决策只修上述既有配置提交，不扩展留存产品能力。确定性文件/PG复现是局部写放大
与控制覆盖证据，不是历史 service 累计10m超时/原导出 running 的唯一根因证明。
旧0014自验/独立失败与同源码收尾完整通过均保留，不以局部修复或最后一次绿抹消。

## 决策

1. SetRetentionPolicy 显式使用 UpdateControl。每次实际 Save 冲突后，在新鲜 control
   上重新核对当前租户存在，再合入本次原配置和一次 retention_policy.set 事实；
   不保存旧物化快照覆盖并发 control。租户已不存在仍404、零配置/事实成功提交。
2. v2 不物化/替换 hot/cold 证据，不 Get/Put WORM。保留并发导出终态、lease、selected/
   生成页/sealed阶段、恢复决定、当前Hold、另一租户策略和事实；取消不回到running，
   健康续期不退回旧时间，晚owner不能发布。原当前Hold/必要读自审计、owner/阶段
   fencing与共享128/32队列、running2/tenant1预算继续独立权威。
3. 原字段校验、租户/权限、HTTP错误与事实编码保持。相同值的再次配置仍各保存一次
   原配置事实，不新增no-op或请求幂等承诺。相同租户策略仍为原有配置替换，不在此
   引入策略版本、条件更新、批准或生命周期协议。
4. 原一次operation deadline、有限冲突重试/退避与取消/超时分类不变，不按attempt
   重新计时。Save失败/未知返回错误，不报告配置成功；真正已耐久的配置与事实不
   撤销，须只读核对，不能把fsync/rename/关闭/取消错误当回滚或自动重发依据。
5. 仅改变配置提交，不执行归档/删除，不缩短任何已写对象COMPLIANCE、不释放对象
   或其他Hold。此写切片当时未改GetRetentionPolicy；其后续控制面读取见ADR-0044。
   EvaluateRetention/通用Store.Update/v1兼容与共享control历史/原扫描成本未整体改造；
   不增加M4版本保全/生命周期或M5业务执行。

## 验证、兼容与限制

修前真实两租户文件/归档、原认证selected计划及当前Hold：成功和未知temp阻断Save
均替换四个原hot/cold inode。修后核对原字节/版本/inode、完整逻辑证据/邻居control/
原事实与重启，未知temp原样保留；配置本身零源Get/Put、零独立读事实，当前Hold仍
拒绝导出访问。实际Backend.Save另覆盖有限冲突/耗尽、明确失败、真正提交后错误、
实际deadline、取消及提交后取消；事实与配置同次提交，失败不泄漏半份控制状态。

独立PG17 pools用真实control行锁及pg_blocking_pids确认Save已在途，再提交并发
取消或续期、恢复决定、当前Hold和另一租户策略。selected、真实生成页、sealed三
阶段均核对实际版本增量、完整证据与晚owner零发布；续期推进共享观察时钟并核对
当前owner运行权，不以未来心跳/旧时钟猜健康。另以自有租户缺失故障验证重试重判
404、零额外Save；不新增租户删除API。所有自有goroutine早退也取消/join。

无新字段/路径/scope、SQL、topic、Proto方法、持久/密封格式或迁移。文件仍单写者，
共享API/worker使用PG；沿用完整control（含任务/关联/lease/阶段/决定）、ledger/hot/
journal/确认/原密钥备份及停写升级/回滚。旧writer仍可能覆盖字段，不能混跑；不清
未知对象/temp/历史/旧卷，不把终态退回pending，不改变生产deadline或工程阈值。

全service race/JSON逐测试与原导出阶段、定向/真实PG、完整quality/Web/security及
随后独立验收分别绑定源码留证。局部少写不是时延SLO、生产容量或全部累计耗时/
历史running根因闭环，不能以专项替代全量。M1/M2/M3整体Partial，M4/M5及整栈/
Hosted Login/容量/容灾/正式合规独立待办；安全扫描非零仍阻塞发布，不自授豁免。
