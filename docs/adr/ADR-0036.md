# ADR-0036: 文件读自审计描述符的关闭与夹具生命周期

状态：Accepted  
日期：2026-10-18  
关联：ADR-0017、ADR-0019、ADR-0033

## 背景与有限范围

文件后端为读自审计保留 O_APPEND 描述符，但 Close 原来仅关闭 flock。持有旧 Store
引用时，实际 trail 描述符仍可用，甚至在新 writer 取得 flock 后继续追加；Close 还
可能在一个实际 trail append 尚未退出时释放锁。两个常用 service 文件夹具未注册
Store.Close，已结束测试的 flock/trail 依赖对象回收或进程退出而非显式清理。

本决策只修复该资源生命周期，不新增治理能力。确定性回归保留 Service/文件引用、
观察实际 descriptor 和 flock，不用 GC 后恰好为零的句柄数冒充正确 teardown。旧
service 累计10m超时、原导出 running 的唯一根因仍未确定；保留旧0014自验/独立失败
及同源码最终完整通过，不能以此次关闭修复或全量通过改写这些结果。

## 决策

1. fileBackend.Close 使用原 trail mutex，与实际 trail 读/追加/压紧串行。已经持有
   mutex 的追加先按原 Write/Sync/目录边界完成或报错，Close 才关闭持久 trail fd，
   然后关闭 flock fd；不能先放锁而让旧追加继续。关闭不新增或删除任何 fsync，不
   重写/删除 control、hot、ledger、trail、未知 temp 或 WORM，不推断未知事实成功。
2. 即使 trail close 失败，也尝试关闭 flock，errors.Join 保留两条真实错误。两个
   descriptor 都只消费一次，清空内部引用，重复 Close 返回第一次的组合结果而非
   重试已消费的 fd 或把之前错误变为成功。错误不证明实际已提交的追加被撤销；必须
   只读核对原事实，不以关闭失败授权自动重发或业务执行。
3. 关闭标记在同一 mutex 下设置；后续文件/内存后端的 trail 读取与追加返回原标准
   os.ErrClosed，不使用旧 fd 或重新打开 trail。失败关闭读自审计因此不能输出回执
   等受保护读结果，也不增加成功读事实。原取消检查、一次读预算、身份/租户绑定、
   HTTP 安全分类/no-store 及原元数据语义不变，无新线面错误码或权限。
4. testService 和 adminTrailTestService 在打开真实文件 Store 后立即注册 cleanup，
   在后注册的 IO/后台 join cleanup 之后、TempDir 移除之前调用 Close 并报告错误。
   正常返回/早退共用该路径；显式重启已 Close 的健康句柄可再次 cleanup，不重复
   OS close。保留全部真实摄入/Put/Get/Save/append/fsync、样本和断言，不转内存，
   不改 TMPDIR、原5秒导出等待、10m包超时、生产 deadline 或其他任务的资源。
5. 调用方仍须先停止并 join API/worker 工作，再关闭 Store。本 mutex 只协调 trail
   生命周期，不是通用 Store 全方法的关闭 fencing、后台任务收集、远端物理停止或
   新 shutdown 协议。导出终态不回退，lease/阶段 fencing、当前 Hold、自审计与共享
   128/32、running2/1仍独立权威，审批不是执行。

## 验证、兼容与限制

无新字段、路径/scope、SQL、topic、Proto方法、持久/密封格式或迁移。误用已关闭的
trail 现在报错，不再在锁释放后追加；关闭错误可被调用方观察，不能吞掉换成功。既有
文件单写者、私有权限/descriptor-relative安全边界、备份/停写升级与回滚要求保持。

回归先在原生产源码上复现：实际 trail fd 在 Close 后仍打开、锁先释放、旧 writer
改写 successor 的 trail、两种文件夹具跨子测试保留两个 fd。随后覆盖未打开/内存/
追加/压紧后的实际关闭、两条关闭错误同时保留/一次消费、真实追加目录同步暂停时
Close 等待、原 inode/字节/未知 temp/重启事实不变，以及关闭后回执自审计失败零输出。
夹具回归只查看当前测试进程的精确自有路径 descriptor 元数据，不记录路径或原内容。

全 service race/JSON逐测试及原导出阶段、真实文件回执重启和独立PG pools复核分别
留证；完整quality/Web/security与随后独立验收绑定同一稳定源码。定向通过不替代
全量，也不从一次包耗时下降、瞬时Sync栈或GC回收推导唯一根因、磁盘归因、生产容量
或长期稳定性。M1/M2/M3整体仍Partial，M4/M5、整栈/Hosted Login、容量/容灾/正式
WORM合规独立待办；安全扫描非零继续阻塞发布，不改规则/阈值或自授豁免。
